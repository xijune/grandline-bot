```
POST /api/battles/pvp/challenge
{ characterId, targetId }
```

## Duel amical (équipage)

```
GET  /api/crews/duel-amical/etat?characterId=
POST /api/crews/duel-amical/defier { characterId }           → mode ouvert
POST /api/crews/duel-amical/defier { characterId, cibleId }  → membre équipage
POST /api/crews/duel-amical/accepter { characterId, duelId }
POST /api/crews/duel-amical/refuser  { characterId, duelId }
POST /api/crews/duel-amical/annuler  { characterId, duelId }
```

Live : `defier` sans cible → **201** défi ouvert
```json
{ "defi": { "id", "statut":"ouvert", "mode":"ouvert", "texte":"propose un duel amical…" } }
```

## État bot

- Level 5 → **pas de challenge PvP agressif** jusqu’au 30
- Duel amical ouvert créable
- Accept d’un défi tiers = attendre qu’un joueur relève
